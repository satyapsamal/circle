# Circle

Circle is an independent, student-built platform designed to make BBA learning simpler, more organized, and accessible in one place.

## Features

- **Learn** — Watch BBA lectures and continue from where you left off.
- **Ask** — AI-powered assistance for academic questions and concepts.
- **Lecture Progress** — Automatically keeps track of your latest lecture.
- **My Notes** — Take and manage notes for individual lectures.
- **Personal Profile** — Personalised student experience with profile support.
- **Responsive Design** — Optimised for both desktop and mobile.
- **Simple Interface** — Minimal, focused interface built for students.
